Output

Ready. Edits are validated before they are written; a config that
fails validation is reverted, so a bad edit is never left on disk.

How this works

Save writes config/*.json and runs the validator. If validation fails the previous file is restored.

Publish rebuilds config/config.bundle.js, which is what the game actually loads. Reload the game to see the change.

Structure is checked here. Whether a level is winnable is not — that needs the simulation. Run T.balance(400) in the game after changing physics, pitch or level positions.
